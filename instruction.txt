The GEARBOx Ontology excel file is U Chicago prepared for us, this includes the information we want to extract from the notes, their data types, examples, answer length, and enumerations of the answer list.

The input folder contains three example clinical notes from U Chicago.

1. run the tools_excel2json notebook, the goal is to convert the excel file to json, to be used in the Azure Openai function calling. YOu need to specify three paramers 

input: the excel file name
output = the output json file name
sheet = the sheet name of the excel file

After this program, a json file would be generated.

2. run the gpt_tool_azure notebook, the program will call openai to extract information from the clinicals notes in the input folder specified by the json file output from the first step. The output will be an excel sheet.
